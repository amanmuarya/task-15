# Array Operations Analyzer

## Objective
The objective of this assignment is to create JavaScript functions that receive an array as an argument and perform various operations on it. This includes finding the maximum number, calculating the sum of all elements, and counting the number of odd numbers.

## Features & Tasks
This program demonstrates the use of different types of JavaScript functions to process a dummy array. It performs the following operations:

* **Find Maximum Number:** Uses an **Arrow Function** to iterate through the array and return the largest number.
* **Calculate Sum:** Uses an **Anonymous Function Expression** to add all the elements of the array together and return the total sum.
* **Count Odd Numbers:** Uses a standard **Named Function Declaration** to count how many odd numbers exist within the array.

## Instructions Implemented
* Each operation is separated into its own distinct function.
* Every function takes an array as its argument.
* Three different function declaration styles are utilized (Arrow, Anonymous, and Named).
* A dummy array is included for testing purposes.
* All results are output to the console.

## Prerequisites
To run this script, you will need an environment that can execute JavaScript:
* **Node.js** installed on your machine.
* Or any modern web browser (like Chrome, Firefox, or Edge) with Developer Tools.
